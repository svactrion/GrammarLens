# 1.3.0 App Store assets

The set uploaded to App Store Connect for version 1.3.0 (build 6), submitted
for review on 2026-10-16. Real build 6 screens, demo learner "Sam", Fox,
Glacier Peak, light mode, 9:41. English only (the app's only localization).

Made by Codex with the `tool/marketing/` pipeline (separate capture
simulator and database, frame, caption, PNG). The working files (raw
captures, SVG sources, previews, zips) were deleted on 2026-10-16; only
these finals are kept.
