# UI polish — asset manifest

App-ready files in `docs/design/ui-polish/handoff/assets/` (WebP, transparent
background). Generated by the owner with an image tool from the briefs in
`docs/design/ui-polish/asset-requests*.md`, converted on 2026-11-17. Move them
into `assets/` (folder layout is the implementer's choice) and register the
folder(s) in `pubspec.yaml`. Do not upscale; do not re-encode below quality 80.
