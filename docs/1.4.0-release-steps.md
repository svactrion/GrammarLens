## 1. Build (owner, on `main`)

Flutter 3.44.6. From the repository root:

```bash
git pull origin main
```

```bash
flutter pub get
```

```bash
flutter analyze
```

```bash
flutter test
```

Expect 2409 tests, about 1.5–3 minutes (the debug-panel real-SQLite stall
is fixed, build log 2026-11-03).

```bash
./scripts/preflight.sh
```

`preflight.sh` checks the Privacy Policy / Terms URLs, `config/prod.json`'s
`PROXY_BASE_URL`, `APP_TOKEN` (it must match the deployed proxy; unchanged
since build 6) and the fallback pool's 7 sets, and removes `.DS_Store`
files under `assets/`. `config/prod.json` has all three keys set,
`REVENUECAT_API_KEY` included (checked 2026-11-03, values not printed).

```bash
flutter build ipa --release --dart-define-from-file=config/prod.json
```

No other define. Default App Store export, automatic signing, team
`37U9L67C2J`.

## 2. Check the build

Read the version from the archive; expect `1.4.0` and `7`:

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/Info.plist
```

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/Info.plist
```

Then the IPA check (audit finding #10): it prints the IPA's version and
build again and fails if a developer tool's text is in the compiled code,
or if the release control string is missing:

```bash
./scripts/release_ipa_check.sh build/ios/ipa/grammar_lens.ipa
```

Also confirm the eight languages are in the bundle (`CFBundleLocalizations`:
en, ja, ko, es, pt-BR, tr, ar, de):

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleLocalizations' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/Info.plist
```
