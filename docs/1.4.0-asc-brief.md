## 0. Rules

1. **Never press Submit for Review.** Do not create a `reviewSubmissions`
   item, do not add items to one, do not call any submission endpoint, do
   not release a version. The owner submits, in the web interface.
2. **Never touch 1.3.0.** Its version, localizations, screenshots and
   review details stay as they are. Every write goes to the new `1.4.0`
   version or to the app-level records named in §6.
3. Do not change prices, subscriptions, in-app purchases, territories or
   the age rating declaration except as §6 says (the age rating only with
   the owner's written answers).
4. Delete nothing outside the 1.4.0 version. Inside it, delete only what
   you uploaded yourself, and en-US's copied 6.3" set (§5.4 step 14),
   after the owner's OK at checkpoint 3.
5. **Credentials:** the API key (`.p8`), key ID and issuer ID come from the
   owner as environment variables only. Never write them to a file in the
   repository, a log, a commit or a report.
6. **Code:** the screens come from **build 7's source, `c37757a`**
   (`1.4.0+7`, on TestFlight since 2026-11-03). Capture in a separate git
   worktree at `c37757a` (detached; never switch the owner's checkout).
   Make and commit the rig changes on `main` (files under `tool/` and the
   delivery folder `screenshots/1.4.0/` only), and bring them into the
   worktree with `git checkout main -- tool/` before each capture. Before
   each capture, `git diff --stat c37757a -- lib ios assets pubspec.yaml`
   in the worktree must print nothing. Never edit `lib/`, `ios/`,
   `proxy/` or tests; if the capture needs an app change, stop and report.
7. **Simulators:** the dedicated store simulators only (the UDIDs in
   `tool/marketing/store_130/capture.sh`, or new ones made for this job).
   Never uninstall, erase or reset a simulator or device the owner uses.
8. **Git:** stage exact paths, small commits, no force push, no history
   rewrite. Push only at a checkpoint the owner has approved.
9. Stop at each checkpoint (§8) and wait for the owner.

JWT (ES256) from the owner's key, `aud` `appstoreconnect-v1`, 20-minute

2. `GET /v1/apps/{id}/appStoreVersions?filter[platform]=IOS`: 1.3.0 is
