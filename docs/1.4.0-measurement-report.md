## 6. The cost model (planning figures)

Measured per call (this run, list prices): generation $0.0078 per 5-item set (G-D, Sonnet 5.5 low, D3); scoring $0.0015 per 5-answer call with Haiku 5.5 (C8) and $0.0187 with Sonnet 5.5 (C4), both D3 + D11. A 5-question practice session therefore costs ≈ $0.0093 with Haiku scoring and ≈ $0.0264 with Sonnet 5.5 scoring; costs are scaled by question count below (a fixed prompt share makes short sessions slightly dearer per question than this).

| Scenario (per user per month, 30 days) | Haiku scoring | Sonnet 5.5 scoring |
|---|---|---|
| Free: the shared Daily Test and one 3-question practice a day | $0.17 | $0.48 |
| Premium light: 1 session of 5 a day | $0.28 | $0.79 |
| Premium heavy: 5 sessions of 5 a day (the cap) | $1.40 | $3.97 |
| **1000 users** (90 % free, 8 % light, 2 % heavy; an assumed mix) plus the shared Daily Test with its check ($0.07 a day) | $203.20 | $573.10 |

The Daily Test costs the same at any user count (one set a day, P14's single-review check included). The practice figures assume every user uses the full quota every day, so they are ceilings.
