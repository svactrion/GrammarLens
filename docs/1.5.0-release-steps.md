**Status (2026-11-21): merged into `main`, version `1.5.0+8`; not built
for the store, nothing uploaded, nothing submitted.** `ui-polish-widgets`
(the UI polish, SPEC v14; the home-screen widgets; the daily reminders; the

an appearance change while open. On that `main`: `flutter analyze` clean,

`flutter build ios --release --no-codesign` succeed (app and widget
extension both 1.5.0 (8)), `preflight.sh` passes. The Worker for 1.5.0 is

TestFlight, the store texts and screenshots, the submission. Record of the
preparation: [`1.5.0-release-progress.md`](1.5.0-release-progress.md).

1.4.1): the paywall's derived-price lira symbol and the storage reset gate

and the widget extension's `Info.plist` read `$(FLUTTER_BUILD_NAME)` /
`$(FLUTTER_BUILD_NUMBER)`, and no test or `lib/` file pins it (checked
2026-11-21).

## 1. Build (owner, on `main`)

Flutter 3.44.6, Xcode 27.2. From the repository root:

```bash
git switch main
```

```bash
git pull origin main
```

```bash
flutter pub get
```

```bash
flutter analyze
```

```bash
flutter test
```

Expect **2939 tests**, all passing (about 1.5–2 minutes).

```bash
./scripts/preflight.sh
```

It checks the Privacy Policy / Terms URLs, `config/prod.json`'s
`PROXY_BASE_URL` and `APP_TOKEN` (unchanged since build 6; the Worker
deployed on 2026-11-19 takes the same token) and the fallback pool's 7 sets,
and removes `.DS_Store` files under `assets/`. `config/prod.json` has all
three keys set, `REVENUECAT_API_KEY` included (checked 2026-11-21, values
not printed).

Resolve the Swift packages first (build 7's lesson: the Crashlytics
upload-symbols script was missing until they were resolved):

```bash
cd ios && xcodebuild -resolvePackageDependencies -workspace Runner.xcworkspace -scheme Runner && cd ..
```

**Signing, new in 1.5.0.** The app now has two targets that are signed:
Runner (`com.ahmettayfur.grammarlens`) and the widget extension
`GrammarLensWidgets` (`com.ahmettayfur.grammarlens.widgets`), both team
`37U9L67C2J`, automatic signing, both with the App Group
`group.com.ahmettayfur.grammarlens` in their Release entitlements. Before
the export needs: the extension's App ID and the App Group registered and
enabled on **both** App IDs in the developer account (done for your device
builds since fix round 3; with automatic signing Xcode makes the
distribution profiles for both at export). If the export stops on a
profile or capability error for `GrammarLensWidgets`, open
`ios/Runner.xcworkspace` → target GrammarLensWidgets → Signing &
Capabilities, let Xcode repair it, and run the build again. Push
Notifications are **not** needed (the reminders are local).

```bash
flutter build ipa --release --dart-define-from-file=config/prod.json
```

No other define. Default App Store export, automatic signing.

## 2. Check the build

`flutter build ipa` prints the version and build in its App Settings
Validation; expect `1.5.0` and `8`. Reading them from the archive, for the
app and the widget extension (both must say 1.5.0 and 8):

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/Info.plist
```

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/Info.plist
```

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleShortVersionString' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/PlugIns/GrammarLensWidgets.appex/Info.plist
```

```bash
/usr/libexec/PlistBuddy -c 'Print :CFBundleVersion' build/ios/archive/Runner.xcarchive/Products/Applications/Runner.app/PlugIns/GrammarLensWidgets.appex/Info.plist
```

(The release build of 2026-11-21, `--no-codesign`, read 1.5.0 (8) for
both.)

Then the IPA check. Since 2026-11-21 (`080f3d1`) it also checks the widget
extension: it fails if `GrammarLensWidgets.appex` is missing from the IPA,
if its version or build differ from the app's, or if the app or the
extension is not signed with the App Group `group.com.ahmettayfur.grammarlens`.
The old checks are unchanged (the IPA's version and build; no developer
tool's text in the compiled code; the release control string found).
Tested on IPAs made from the release build, not yet on a store IPA:

```bash
./scripts/release_ipa_check.sh build/ios/ipa/grammar_lens.ipa
```

Expect, among its lines: "version 1.5.0, build 8", "Widget extension:
version 1.5.0, build 8 (equal to the app's)", "Runner.app is signed with the
App Group …", "GrammarLensWidgets.appex is signed with the App Group …",

The eight languages in the bundle (`CFBundleLocalizations`: en, ja, ko, es,
